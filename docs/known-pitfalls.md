# Known pitfalls

Problems hit during development — either to avoid them in the future or to fix later on.

| Pitfall                                                       | Symptom                                                                                                                                               | Workaround / fix                                                                                                     | Status     |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ---------- |
| Vitest `forks` pool under the Bun runtime (no Node installed) | `child.channel?.unref is not a function`, no tests run                                                                                                | `pool: "threads"` in `vite.config.ts`                                                                                | workaround |
| TypeScript 7 removed `baseUrl`                                | `TS5102: Option 'baseUrl' has been removed`                                                                                                           | Use `paths` only                                                                                                     | fixed      |
| Radix `Tooltip` on touch devices                              | Tapping the info icon does nothing on iOS: Radix closes the tooltip on pointer down / click, and Safari does not focus buttons on tap                 | Controlled tooltip; the trigger calls `preventDefault()` (skips Radix' handlers) and toggles it (`FieldControl.tsx`) | workaround |
| Chromium emulation focuses tapped buttons                     | Mobile e2e tests pass although a real iPhone fails (focus opens tooltips)                                                                             | Blur on focus in the test to mimic Safari                                                                            | workaround |
| Shiller S&P 500 data are monthly _average_ prices             | Trading on a signal at the same month's average price looks ahead ~½ month; SMA strategies looked better than buy and hold                            | SMA signals on `priceType: "average"` data act one month later (`signalLagMonths`)                                   | workaround |
| Bun's `fetch` against FRED                                    | `ECONNRESET` in `scripts/fetch-data.ts`; FRED also rejects browser user agents                                                                        | Download via `curl` with its default user agent                                                                      | workaround |
| MSCI end-of-month API                                         | Rejects `end_date` far in the future; NETR history only from end of 2000                                                                              | Use today's date; MSCI datasets start 2001-01                                                                        | open       |
| shadcn `Slider` puts `aria-label` on the root                 | Thumb (`role="slider"`) has no accessible name; Playwright `getByRole("slider", { name })` fails                                                      | `src/components/ui/slider.tsx` forwards `aria-label` to the thumbs                                                   | fixed      |
| `vite preview` reused by Playwright                           | e2e runs against an old build when a previous preview server is still running (`reuseExistingServer`)                                                 | Kill the old `vite preview` before `bun run test:e2e`                                                                | open       |
| `shadcn add` without `shadcn init`                            | Generated components import `cn` from the npm package `"cn"` instead of `@/lib/utils`, and no theme CSS variables are written                         | Fix the import after adding a component; theme vars live in `src/index.css`                                          | open       |
| Tailwind utilities vs. theme overrides in `index.css`         | Rules inside `@layer base/components` lose against utility classes such as `rounded-md` on shadcn components                                          | Keep the notebook-look rules unlayered (unlayered CSS beats every layer), no `!important` needed                     | workaround |
| Bear markets on monthly average data                          | The S&P 500 (Shiller, monthly averages) misses 2020 (−18.9 %) and 2022 (−19.3 %) as bear markets; MSCI (month-end) lists both                         | Note under the bear market table for `priceType: "average"` data                                                     | open       |
| Worktree without its own `node_modules`                       | `vite` resolves packages from the parent checkout and fails on missing `@fontsource/*` CSS                                                            | Run `bun install` in the worktree                                                                                    | workaround |
| SVG colors from CSS variables                                 | Scenario colors are `var(--series-N)` strings; they can't be concatenated with an alpha suffix (`${color}33`)                                         | Use `fillOpacity` / `opacity` instead of hex alpha                                                                   | workaround |
| dnd-kit keyboard sorting in tests                             | Arrow keys pressed right after Space do nothing: dnd-kit measures the tabs in the next frame; in jsdom all rects are 0, so no sorting at all          | Test drag and drop in Playwright; wait for the live-region announcement plus ~150 ms after pick-up                   | workaround |
| Web Worker requests cannot be cancelled                       | Dragging a slider queued one simulation per step; results arrived long after the user stopped                                                         | `SimulationClient` keeps its own queue and replaces queued requests of the same kind (REQ-009-03)                    | workaround |
| Volatility drag from monthly data                             | Trailing variance of monthly (and for the S&P 500 monthly-average) returns understated daily variance; 3× CAGR 2001–2025 was 21.7 % instead of 16.1 % | Each month stores the realised variance of its daily returns (spec 010)                                              | fixed      |
| French data library daily file rounds to 0.01 %               | The daily RF column is 0.00 or 0.01 % a day (~2.5 % p.a. steps); compounding it gives wrong T-bill rates and monthly returns                          | Returns and rates from the monthly file, only the variance from the daily file                                       | workaround |
| French data library lags ~2 months                            | The latest S&P 500 months (Shiller) have no daily variance yet                                                                                        | Those months use the scaled estimate like the months before 1926                                                     | open       |
